# 服务行业 AI 客服 Agent

## 场景与问题

服务行业咨询覆盖报修、缴费、车位、访客、投诉和政策查询等主题。纯 FAQ 难以处理多轮上下文和实时业务查询；单次模型问答也无法安全完成查费、创建工单等操作。

## Agent 架构

采用可编排的 Agent 工作流承载对话状态和多分支业务路径：

1. 多渠道接入后恢复会话上下文与持久化记忆。
2. 使用 LangGraph4j 编排意图识别、知识检索、受控工具调用、重试与转人工等节点。
3. 使用 LangChain4j 封装模型调用、提示词、文档切片和向量检索，构建物业 RAG 知识库。
4. 对需要实时数据或办理业务的请求，通过受控插件调用收费、报修、门禁等业务系统；将调用状态纳入 Agent 流程，而不是让模型直接操作底层系统。
5. 记录每轮 Agent 执行与工具结果，支持多轮追问、失败重试和人工接管。

## 适用范围

适用于需要将知识问答与实时业务办理组合起来的物业客服及服务运营场景。此处为基于项目经验抽象的参考架构，工具权限、知识审核和转人工策略需按具体业务配置。
